ModelValue Radar helps you compare AI model prices for your own workload: enter users, calls and tokens, estimate a monthly budget, and compare up to three candidates with transparent assumptions.

## Included

- Search, combined price/context/modality/API-parameter filters, pagination and workload-cost ranking.
- A text-token calculator with cache-read pricing, request fees, context/output checks and daily/monthly/annual estimates.
- Three-model comparison tables, token-price/monthly-cost charts, price scatter and accessible chart data.
- Share links containing model IDs and workload in the URL fragment; copied results retain source and calculation warnings.
- Six transparent scenario filters, English/Chinese, dark/light themes and responsive layouts.
- Validated OpenRouter adapter, on-demand browser loading, local import, stale/error handling and an optional metadata-only source check.
- GitHub Actions CI/Pages workflows, contributor guides and dependency license notices included in builds.

## Try it

Repository: `REPO_URL`

Hosted demo, only if deployed and verified: `DEMO_URL`

From the extracted/cloned repository, with Node 24 and npm:

```bash
npm ci
npm run dev
```

Load the official catalog, adjust your workload, and select up to three models. No account, database or inference purchase is needed. Public catalog access was observed without a key; future upstream changes may require the documented error/import fallback.

## Validation and limits

The 2026-11-01 local engineering review recorded 94 unit/component tests and 72 Playwright test cases passing (24 flows across 375px, 768px and 1440px). Production asset loading under `/modelvalue-radar/` was checked. This does not claim a successful remote deployment, real-device coverage or universal accessibility conformance.

Price rankings are not quality rankings. Cost estimates exclude tier/long-context premiums, cache writes, media, tools, taxes, platform fees and routing differences. No capability benchmark or historical price dataset is included. Shared links do not freeze prices.

MIT covers original code/docs, not model data or brands. The project ships no full catalog. Public use of the integration and screenshots still requires a source-rights review; the scheduled source check is disabled by default. See the repository's data policy and third-party notices before deployment.

## Contribute

Three small, independent starter tasks are prepared in `docs/good-first-issues/`: accessible form hints, displaying request fees in model details, and Escape-to-clear search. Bug reports should include reproduction steps and source retrieval time, without private workloads or complete third-party catalogs.
