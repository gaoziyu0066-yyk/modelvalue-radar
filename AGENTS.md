# ModelValue Radar

- Work inside this repository. Do not move unrelated parent workspace files.
- React + strict TypeScript + Vite, static GitHub Pages deployment.
- Never invent model prices, capabilities, benchmarks, or historical snapshots.
- Keep model data in memory; do not commit or mirror a third-party catalog without explicit redistribution permission.
- Mark synthetic test fixtures as test-only. Do not serve them as production models.
- Cost formulas, parser, filters, and share state need regression tests when changed.
- Run `npm run lint`, `npm test`, `npm run build`, and relevant Playwright tests.
- No credentials in Vite variables. No remote push or publication without user authorization.
